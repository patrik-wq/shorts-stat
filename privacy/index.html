shorts-stat – Privacy Policy

Last updated: 16 October 2026

What data the app accesses

With the channel owner's consent (Google sign-in, read-only permissions “youtube.readonly” and “yt-analytics.readonly”), shorts-stat reads:

  • the list of the channel's own uploaded videos (video ID, title, publish date, duration);
  • aggregated, anonymous statistics of these videos (views, watch time, average view duration, subscribers gained, views by country).

It does not access viewers' personal data, comments, e-mails or any other Google data.

How the data is used

Only to create internal performance reports for the channel owner (for example which videos perform well and in which countries).

Storage and security

The data is stored on a private server operated by the owner. The sign-in tokens are kept in a protected credential store that only the owner can access.

Sharing

The data is not shared, sold or transferred to anyone, and it is not used for advertising.

Google API Services User Data Policy

shorts-stat's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

The data is kept as long as the owner needs the reports. Access can be revoked at any time at myaccount.google.com/permissions. After revocation, or on request, the stored data is deleted.

Contact

Please use the support e-mail address shown on the Google sign-in screen of this app.
